Hybrid Recommendation System
----------------------------

What is this?
- It is a helper that suggests fun events for people.
- It looks at what you like, what people like you enjoy, and what is popular now.

The data it reads
- users.csv: who the people are and what they like.
- events.csv: the list of events and their details.
- attends.csv: which users went to which events and when.
- follows.csv: which users follow which artists.
- artists.csv: info about the artists.

Three brains working together
1) Knowledge brain (profile match):
   - Matches your interests (like music or dance) and your region to event types and regions.
   - Gives each event a KnowledgeScore.

2) Graph brain (friends-of-friends):
   - Builds a network of users, events, and artists.
   - Finds users like you and recommends events they enjoyed.
   - Gives each event a GraphScore.

3) Trend brain (what is hot now):
   - Looks at recent attend data (last days/weeks).
   - Picks events that are getting more visits.
   - Gives each event a TrendScore.

The hybrid blender
- Mixes KnowledgeScore, GraphScore, and TrendScore.
- Uses different weights depending on how active you are:
  * New/cold user: trusts profile more.
  * Active user: trusts similar users more.
  * Trending focus: trusts the trend brain more.
- Creates a FinalScore and sorts events.

Explanations
- Each suggested event comes with a short reason, like:
  * "Matches your interests"
  * "Popular among similar users"
  * "Trending this week near you"

How to run (from scratch)
1. Open a terminal and go to the project folder.
2. Create a virtual environment:
     python -m venv .venv
3. Activate it:
     Windows:  .\.venv\Scripts\activate
     Mac/Linux: source .venv/bin/activate
4. Install the project:
     pip install -e .[dev]
5. Make sure the CSV files are in the data/ folder.

Two ways to use the system
--------------------------

A) Recommendation Engine:
   python run_recommend.py
   - Pick 1-4 from the menu
   - Enter a user id and how many results you want
   - See scores and explanations

B) System Pipeline (step navigator):
   python run_pipeline.py
   - Just type a step number (1-7) and press Enter
   - Type 8 to run all steps one after another
   - Type 0 to quit
   - No need to type long file paths!

System Pipeline Steps
---------------------

  Step 1: Dataset Overview
    Shows how many users, events, artists, and connections there are.

  Step 2: Build & Visualise Graph
    Builds the graph and draws a small piece of it.
    Saves: pipeline/step2_graph.png

  Step 3: Basic Recommendations
    Picks a user and shows two ways to recommend:
    a) Through shared categories (User -> Event -> Category -> New Event)
    b) Through similar users (User -> shared events -> Similar User -> New Event)
    Saves: pipeline/step3_basic_reco.png

  Step 4: Full Model Pipeline + Evaluation
    Runs all three brains, blends them, adds explanations and checks how accurate the system is.

  Step 5: Highlight Recommendation Paths
    Shows the exact path from the user to each recommended event with colour-coded arrows.
    Saves: pipeline/step5_paths.png

  Step 6: Interactive Dynamic Input
    Interactive! You can:
    - Pick any user
    - Filter by category (like "music" or "dance")
    - Compare two users side by side
    - See who the most active users are
    Saves pictures for each query.

  Step 7: Advanced Graph + Scoreboard
    The big picture: shows many recommendation paths at once,
    a scoreboard, and which nodes are most important.
    Saves: pipeline/step7_advanced_graph.png

- Tip: If the picture window blocks, set MPLBACKEND=Agg before running.

What you can change
- Add more user interests or regions in users.csv.
- Tune the weights in the hybrid blender if you want a different mix.
- Change the time window for trends to be shorter or longer.

Remember
- The system does not change your CSV files; it only reads them.
- The better the data, the better the suggestions.
